# Copy Slack

## 概要

本 WEB アプリはポートフォリオ用に作成された Slack の簡易コピーです。Udemy で React, Next.js を学習し、そのアウトプットとして作成しております。<br>
バックエンドは golang で構築し、gRPC で front と通信しますが、ローカルでは`json-server`をバックエンドに見立てて起動します。<br>

## 技術要素

### フロントエンド

|             項目              |   内容   |
| :---------------------------: | :------: |
|      言語/フレームワーク      | Next.js  |
|      CSS フレームワーク       |   MUI    |
| 認証方式（localStorage 保存） | トークン |
|     backend との通信方式      |   gRPC   |

### バックエンド

|        項目         |          内容          |
| :-----------------: | :--------------------: |
| 言語/フレームワーク |         Golang         |
|   アーキテクチャ    | クリーンアーキテクチャ |

## 起動方法

### バックエンドと連携して起動

バックエンド側を先に起動しておき、下記を実行

```bash
$ npm install
$ npm run dev
```
